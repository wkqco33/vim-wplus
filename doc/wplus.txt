1. INTRODUCTION                                                  *wplus-intro*

vim-wplus is a dependency-free, all-in-one Vim plugin that replaces over 35
commonly-used plugins with pure VimScript implementations.

Requires Vim 9.1+ with: >
    +job  +channel  +popupwin  +signs  +textprop
<
Verify with: >
    :echo has('job') && has('channel') && has('popupwin') && has('signs') && has('textprop')
<

    multicursor   register      yankhighlight

    lsp           format        outline       fold

The 'repeat' module is autoload-only and has no setup(): it forwards repeatable
operations to tpope/vim-repeat when that plugin is installed. See |wplus-repeat|.

3. INSTALLATION                                                *wplus-install*

vim-plug: >
    Plug 'wkqco33/vim-wplus'
<
Pack: >
    git clone <url> ~/.vim/pack/user/start/vim-wplus
<
Manual: >
    set runtimepath+=~/.vim/pack/user/start/vim-wplus
    source ~/.vim/pack/user/start/vim-wplus/plugin/wplus.vim
<

4. CONFIGURATION                                                *wplus-config*

Disable individual modules (before plugin/wplus.vim loads): >
    let g:wplus_<module>_enabled = 0
    " Example:
    let g:wplus_blame_enabled   = 0
    let g:wplus_ai_enabled      = 0
    let g:wplus_fold_enabled    = 0
<
See |wplus-<module>| sections below for per-module settings.

Full reference: docs/config.md in the plugin directory.

5. COMMENTARY                                               *wplus-commentary*

Toggle comments for the current line, motion, or visual selection.
Comment tokens are read from &commentstring automatically.

Mappings: >
    gcc            Toggle comment on current line
    gc{motion}     Toggle comment on motion range  (e.g. gc3j, gcip)
    gc             Toggle comment on visual selection
<

==============================================================================
6. SURROUND                                                   *wplus-surround*

Add, change, or delete surrounding characters.

Mappings: >
    ys{motion}{c}  Surround motion with c       (ysiw" → "hello")
    yss{c}         Surround current line
    cs{old}{new}   Change surrounding           (cs"' → 'hello')
    ds{c}          Delete surrounding           (ds" → hello)
    S{c}           (Visual) Surround selection
<
Supported: ( ) [ ] { } < > " ' ` and HTML tag (t).

==============================================================================
7. AUTO PAIRS                                                    *wplus-pairs*

Automatically closes brackets and quotes as you type.

  ( → ()    [ → []    { → {}    " → ""    ' → ''    ` → ``

  <BS>  inside empty pair → deletes both characters
  )     if already present → skips (no duplicate)

8. TEXT OBJECTS                                                *wplus-textobj*

Indent block: >
    ii    inner indent block (same level lines)
    ai    indent block + header line above
<
Function argument: >
    ia    inner argument (without surrounding whitespace)
    aa    argument including adjacent comma
<
Works with all operators: d, c, y, v, >, <, =, gq, ...

==============================================================================
9. REPEAT                                                       *wplus-repeat*

Forwards repeatable plugin operations to tpope/vim-repeat. This module does
NOT map |.| itself: doing that correctly requires tracking b:changedtick to
distinguish "a plugin operation ran last" from "a normal edit ran last", which
is exactly what vim-repeat already does.

Without vim-repeat installed, |.| keeps its native behaviour and repeating a
surround or comment operation is not supported. That is deliberate — an earlier
version mapped |.| unconditionally and never cleared its stored sequence, so a
single `gcc` made every later |.| replay the comment toggle.

API for plugin authors (no-op unless vim-repeat is present): >
    call wplus#repeat#set("\<Plug>MyAction", v:count)
<

10. MULTI CURSOR                                           *wplus-multicursor*

Select multiple occurrences of a word and edit them simultaneously.

Mappings: >
    <C-n>    Add next match to selection
    <leader>vx    Skip current match, add next
    <leader>va    Select all matches in buffer
    c        Replace all selected (prompts for new text)
    d        Delete all selected
    <Esc>    Exit multi-cursor mode
<

13. FINDER                                                      *wplus-finder*

Fast fuzzy finder using Vim 9 matchfuzzy() and popup windows.

Mappings: >
    <leader>ff    Find files
    <leader>fb    Find buffers
    <leader>fr    Find recent files (MRU)
<
Popup keys: >
    <C-n> / ↓    Next item
    <C-p> / ↑    Previous item
    <CR>         Open in current window
    <C-v>        Open in vertical split
    <C-s>        Open in horizontal split
    <C-t>        Open in new tab
    <Esc>        Close
<
Configuration: >
    let g:wplus_finder_width_ratio  = 0.7
    let g:wplus_finder_height_ratio = 0.4
    let g:wplus_finder_fuzzy_limit  = 10000
<

14. EXPLORER                                                  *wplus-explorer*

Sidebar file explorer.

Mappings: >
    <leader>e  /  :WexplorerToggle    Toggle sidebar
<
Inside explorer: >
    <CR>    Open file or enter directory
    a       Create new file/directory  (append / for directory)
    dd      Delete. Files and empty directories prompt yes/no (default No);
            a non-empty directory requires typing its name to confirm, since
            the delete is recursive and not recoverable.
    r       Rename
    R       Refresh
    q       Close
<
Configuration: >
    let g:wplus_explorer_max_entries = 1000
    let g:wplus_explorer_max_depth   = 8
<

23. CONFLICT RESOLVER                                         *wplus-conflict*

Detect and resolve Git merge conflicts visually.

Mappings: >
    ]x                  Jump to next conflict
    [x                  Jump to previous conflict
<
Commands: >
    :WconflictNext      Jump to next conflict
    :WconflictPrev      Jump to previous conflict
    :WconflictOurs      Accept ours (HEAD) version
    :WconflictTheirs    Accept theirs (incoming) version
    :WconflictBoth      Accept both versions
<
Choosing a side rewrites the buffer, so those three ship without default keys.
Bind them yourself if you want them: >
    nmap <leader>co <Plug>WconflictOurs
    nmap <leader>ct <Plug>WconflictTheirs
    nmap <leader>cb <Plug>WconflictBoth
<

33. RUN                                                            *wplus-run*

Filetype-aware code runner and build system launcher.

Mappings: >

    <leader>rb  /  :Wbuild    Build project

42. AI ASSISTANT                                                    *wplus-ai*

Integrated AI assistant supporting OpenAI, Claude, Azure OpenAI, and Ollama.

Commands: >
    :WaiComment          Generate comment for current code
    :WaiComplete         Suggest code completion
    :'<,'>WaiRefactor    Refactor selected code (preview before applying)
    :'<,'>WaiReview      Review selected code (bugs, security, suggestions)
    :'<,'>WaiExplain     Explain selected code step by step
    :WaiCommitMsg        Generate commit message from staged diff
    :WaiFixDiag          Fix LSP diagnostic on current line
    :WaiToggleSuggest    Toggle Ghost Text auto-completion
<
All commands show a preview popup — press Enter/a to apply, Esc to discard.

Ghost Text: shows AI suggestion as grey virtual text while typing in Insert
mode. Accept with <Tab> (or your configured key).

Provider configuration: >
    let g:wplus_ai_provider = 'openai'   " 'openai'|'claude'|'azure'|'ollama'
    let g:wplus_ai_api_key  = $OPENAI_API_KEY
    let g:wplus_ai_model    = 'gpt-4o'
<
Ghost Text configuration: >
    let g:wplus_ai_suggest_enabled = 1
    let g:wplus_ai_suggest_delay   = 500    " ms
    let g:wplus_ai_suggest_max_lines = 3
<
See docs/ai.md for the full provider setup guide.
